Trabalho 1

Composição visual e hierarquia na construção de interfaces digitais.

O que é composição visual?

A composição visual é o arranjo organizado e intencional dos elementos visuais dentro de um espaço determinado. É a maneira como dispondo linhas, formas, cores, texturas e espaços para criar uma unidade harmoniosa e eficaz na comunicação visual.

Hierarquia visual

A hierarquia visual define a ordem de importância dos elementos, utilizando tamanho, cor, contraste, espaçamento e tipografia para orientar a leitura e a interação do utilizador. Tem como elementos básicos: Pontos, linhas, formas, cores, texturas e espaço.

Aplicação prática

Nesta página, a hierarquia é criada através do uso de títulos bem definidos, espaçamento consistente, contraste adequado e divisão clara das secções, facilitando a leitura e a navegação.
