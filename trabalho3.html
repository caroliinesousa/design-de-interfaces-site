Trabalho 3

Diferença e relação entre UI (User Interface) e UX (User Experience).

O que é UI?

UI (User Interface) refere-se à parte visual da interface com a qual o utilizador interage. Inclui cores, tipografia, botões, ícones, espaçamento e todos os elementos gráficos que tornam a interface visualmente compreensível e agradável.

O que é UX?

UX (User Experience) diz respeito à experiência global do utilizador ao interagir com um sistema. Envolve usabilidade, acessibilidade, eficiência, facilidade de navegação e a forma como o utilizador se sente ao utilizar a interface.

UI vs UX

  • UI: Foca na aparência e nos elementos visuais.
  • UX: Foca na experiência, eficiência e satisfação do utilizador.
  • UI: Define como a interface se apresenta.
  • UX: Define como a interface funciona e é percebida.

Aplicação prática

Nesta página, a UI é representada pela organização visual, tipografia consistente e uso de cores, enquanto a UX é garantida pela navegação clara, leitura fluida, acessibilidade e estrutura lógica do conteúdo.
