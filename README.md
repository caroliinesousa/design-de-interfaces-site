# 📘 Projeto – Design de Interfaces

## 📌 Descrição Geral

Este projeto foi desenvolvido no âmbito da disciplina de **Design de Interfaces** e tem como objetivo aplicar, de forma prática, os principais conceitos estudados ao longo das aulas, incluindo acessibilidade, usabilidade, design inclusivo, hierarquia visual, emoção, tendências e responsividade.

O site é composto por uma página principal (index) e seis páginas temáticas, cada uma dedicada a um conteúdo específico abordado na disciplina.

---

## 🎯 Objetivos do Projeto

- Aplicar princípios de Design de Interfaces em contexto prático  
- Desenvolver um site acessível, responsivo e inclusivo  
- Seguir as diretrizes das WCAG (Web Content Accessibility Guidelines)  
- Garantir coerência visual e boa experiência do utilizador  
- Demonstrar conhecimento técnico e conceptual da disciplina  

## 📄 Conteúdo das Páginas

### 🏠 Index
Página inicial do projeto, apresentando uma visão geral do site, com navegação clara e acesso a todos os trabalhos desenvolvidos.

### 📘 Trabalho 1 – Composição Visual e Hierarquia
Explora a organização dos elementos visuais, hierarquia tipográfica e uso do espaço para guiar o olhar do utilizador.

### 📗 Trabalho 2 – Imagens, Cores e Compressão
Aborda o uso consciente de imagens, escolha adequada de cores, contraste e importância da compressão para desempenho e acessibilidade.

### 📙 Trabalho 3 – UI e UX
Apresenta a diferença entre User Interface (UI) e User Experience (UX), demonstrando como ambos se complementam numa interface digital.

### 📕 Trabalho 4 – Estética Funcional e Emoção
Analisa como a estética pode provocar emoções positivas sem comprometer a funcionalidade e a usabilidade da interface.

### 📒 Trabalho 5 – Tendências e Responsividade
Explora tendências atuais de design e demonstra, de forma prática, a adaptação do layout a diferentes dispositivos (desktop, tablet e mobile).

### 📓 Trabalho 6 – Acessibilidade e WCAG
Foca nos princípios da acessibilidade digital, nas diretrizes WCAG e nas boas práticas aplicadas ao longo de todo o site.

---

## ♿ Acessibilidade

O projeto foi desenvolvido com foco em design inclusivo, aplicando as seguintes boas práticas:

- Uso de HTML semântico (`header`, `nav`, `main`, `section`, `article`)
- Texto alternativo em imagens (`alt`)
- Contraste adequado entre texto e fundo
- Navegação por teclado
- Skip link para acesso direto ao conteúdo principal
- Layout responsivo e inclusivo

---

## 🎨 Tecnologias Utilizadas

- HTML5  
- CSS3  
- Flexbox e Grid Layout  
- Variáveis CSS  
- Media queries para responsividade  

---

## 📱 Responsividade

O site adapta-se corretamente a diferentes tamanhos de ecrã, garantindo legibilidade e boa experiência do utilizador em:

- Desktop  
- Tablet  
- Dispositivos móveis  

---

## 📌 Considerações Finais

Este projeto demonstra a aplicação prática dos conceitos de Design de Interfaces, equilibrando estética, funcionalidade, acessibilidade e experiência do utilizador. O desenvolvimento teve como foco a criação de uma interface clara, coerente e inclusiva, alinhada com as boas práticas atuais do design web.
